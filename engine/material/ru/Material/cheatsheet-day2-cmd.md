# Шпаргалка ко дню 2: CMD

## Перемещение

| Команда | Что делает |
|---|---|
| `dir` | Показывает содержимое текущей папки |
| `dir /a` | Включает **скрытые** элементы |
| `dir /s` | Обходит вложенные папки |
| `dir /r` | Показывает **альтернативные потоки** |
| `cd папка` | Переходит в папку |
| `cd ..` | Поднимается на уровень выше |
| `cd \` | Переходит в корень диска |
| `D:` | Переключает диск |

## Файлы

| Команда | Что делает |
|---|---|
| `md папка` | Создаёт папку |
| `type файл` | Выводит содержимое |
| `copy a b`, `move a b`, `ren a b` | Копирует, перемещает и переименовывает |
| `del файл`, `rd /s папка` | Удаляет, **осторожно** |

## Цепочки команд, главная идея дня

| Символ | Что делает |
|---|---|
| `>` | Сохраняет вывод в файл, перезаписывая его |
| `>>` | Дописывает в конец файла |
| `\|` | Передаёт вывод следующей команде |
| `findstr текст` | Оставляет только строки, в которых есть заданный текст |

```cmd
findstr /s /i "{FLAG}{" *.*
tasklist | findstr /i chrome
ipconfig > сеть.txt
```

`dir` ищет по **именам**. `findstr` ищет **внутри**. В этом и состоит главный шаг дня.

## Расспрашиваем систему

| Команда | Что сообщает |
|---|---|
| `hostname`, `whoami`, `ver` | Кто вы и где находитесь |
| `whoami /priv`, `whoami /groups`, `whoami /user` | Привилегии, группы и ваш SID |
| `systeminfo` | Полный профиль: версия, домен, память, обновления |
| `net user` | Локальные пользователи |
| `net user <имя> /domain` | Сведения об учётной записи **домена** |
| `tasklist /svc` | Процессы и службы, работающие в каждом из них |
| `sc query`, `net start` | Службы |
| `schtasks /query /fo LIST /v` | Задачи планировщика со всеми подробностями |

## Переменные и PATH

```cmd
set
echo %USERNAME%
echo %PATH%
where notepad
```

## Самый полезный рефлекс

```cmd
команда /?
```

Прежде чем искать в интернете, спросите саму команду.

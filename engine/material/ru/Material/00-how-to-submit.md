# Как сдавать работы и следить за прогрессом

```powershell
Submit-Flag "{FLAG}{...}"      # сдать флаг
Get-Progress                   # ваши баллы
Get-Progress -Detail           # по каждому заданию отдельно
Get-Challenges 2 -Hints        # если застряли
Get-Hint D2-03                 # многоуровневая подсказка, без штрафа
```

Система проверки запускается каждую минуту. Рейтинг курса: **{WEB_URL}**. На сайте также можно сдавать флаги и загружать отчёт в формате `.txt`, `.md`, `.pdf`, `.docx` или `.excalidraw`.

## Сдавать нужно не всё

Некоторые задания проверяются автоматически: задание 2 четвёртого дня и четыре задания по администрированию седьмого дня. Флагов там нет, нужно просто выполнить работу, а система проверки смотрит на ваш диск `H:` и ваше подразделение.

## Отчёты приносят баллы

Их кладут в `H:\{DELIVER_DIR}` с именем по номеру дня: `day1-map.md`, `day2-writeup.md` и так далее до `day7-writeup.md`. Для каждого дня есть шаблон в `\\{DC}\{SHARE_PUBLIC}\{TEMPLATES_DIR}`. Файл из двух строк не засчитывается: ожидается настоящее содержание.

## Ваша почта

```powershell
Get-LabMail
Read-LabMail 1
Send-LabMail -To kollega@{DOMAIN} -Subject "..." -Body "..."
```

Сервер `{MAIL_HOST}`, SMTP 25 или 587 и POP3 110, вход под доменной учётной записью.

## Правила

Ваш участок ограничен вашим подразделением внутри `OU={OU_SANDBOX}`. За его пределами вы обычный пользователь. Не трогайте контроллер домена. Ничего из изученного здесь нельзя пробовать в других местах без явного письменного разрешения.

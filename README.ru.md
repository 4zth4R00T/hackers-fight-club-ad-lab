<p align="center">Windows Server 2025 · семь дней практики · свой флаг у каждого учащегося · сайт с рейтингом</p>

<p align="center"><a href="README.md">Versión en español</a> · <a href="README.en.md">English version</a> · <a href="https://4zth4r00t.github.io/hackers-fight-club-ad-lab/ru/">Страница проекта</a></p>

Этот репозиторий с нуля поднимает контроллер домена на Windows Server 2025, готовый к обучению Windows и Active Directory. Курс рассчитан на семь дней: командная строка, реестр, NTFS, PowerShell, сеть, разведка каталога и групповые политики. В комплекте сайт с рейтингом, внутренняя почта, интранет, обои с именем вошедшего пользователя и скрипты для добавления учащихся и преподавателей из файла CSV.

## Дата актуальности

Лаборатория написана и проверена по сведениям, доступным на **9 ноября 2026 года**, на Windows Server 2025 сборки 26100.

Уязвимости в лаборатории возникают из настроек, а не из незакрытых ошибок, но Windows меняется с каждым накопительным обновлением. Более позднее обновление может закрыть используемое здесь поведение, изменить значение по умолчанию или добавить новую защиту. Прежде чем открывать лабораторию группе, запустите `Test-Lab.ps1`, сами пройдите каждое задание и убедитесь, что всё работает как описано. Если что-то больше не воспроизводится, сверьтесь с заметками к выпускам Microsoft, опубликованными после этой даты.

## Предупреждение

Эта среда уязвима намеренно. Запускайте её только в изолированной сети под вашим контролем: в виртуальной сети VMware, в частной VPN или в учебной локальной сети. Никогда не подключайте её к рабочей сети и никогда не открывайте доступ из интернета. Флаги, пароли и секреты создаются заново при каждой установке, поэтому в репозитории нет ответов.

## Настройка

Всё берётся из `config/lab.config.psd1`. Отредактируйте его до установки.

| Ключ | Назначение | По умолчанию |
|---|---|---|
| `Language` | Язык сообщений и текстов: `es`, `en`, `ru` или `auto` | `auto` |
| `NamesLanguage` | Язык имён подразделений, групп, общих ресурсов и папок: `es`, `en`, `ru` или `auto`, чтобы следовать `Language` | `auto` |
| `Organization` | Название вымышленной компании | `Atlas Corp` |
| `LabName` | Видимое имя лаборатории | `Hackers Fight Club` |
| `DomainPrefix` и `DomainSuffix` | Префикс и суффикс домена. Значения из примера дают `fightclub.lab` | `fightclub` и `lab` |
| `NetBIOSName` | Короткое имя домена | `FIGHTCLUB` |
| `DcHostPrefix` и `DcHostNumber` | Префикс и номер контроллера домена. Значения из примера дают `DC01` | `DC` и `1` |
| `Root` | Папка лаборатории на сервере | `C:\Lab` |
| `GroupPrefix` | Префикс корневого подразделения и групп | `Lab` |
| `FlagPrefix` | Префикс флагов, например `FLAG{...}` | `FLAG` |
| `StudentPrefix` | Префикс постоянного идентификатора каждого учащегося | `alumno` для испанского, `student` для английского и русского |
| `NetworkMode` | `Tailscale`, `VPN`, `VMnet` или `LAN` | `VMnet` |
| `LanIPAddress`, `LanPrefixLength`, `LanGateway` | Статический IP контроллера в локальной или виртуальной сети | `192.168.251.10/24` |
| `DnsForwarders` | DNS-серверы, которым контроллер пересылает всё, что вне домена | Шлюз VMware и два публичных резолвера |
| `VpnInterface` и `VpnClientCidr` | Адаптер и сеть клиентов в режиме VPN | `WireGuard*` и `10.9.0.0/24` |
| `ExtraClientCidrs` | Дополнительные сети, которым разрешено пользоваться службами | пусто |
| `WebPort`, `IntranetPort`, `BannerPort`, `SmtpPorts`, `Pop3Port` | Порты служб | 8443, 80, 1337, 25 и 587, 110 |
| `MinPasswordLength` и `LockoutThreshold` | Политика паролей | 12 и 10 |
| `TimeZone` | Идентификатор часового пояса Windows; пусто, чтобы не менять | пусто |
| `Wallpaper`, `Challenges`, `Mail`, `Web` | Переключатели компонентов | все включены |
| `Weaknesses` | Переключатель каждой намеренной уязвимости, описанной ниже | все включены |

С `auto` язык берётся из языка Windows: сервер на русском использует `ru`, на испанском `es`, любой другой `en`. Если `NamesLanguage` равен `ru`, подразделения, группы, отделы, роли и GPO получают русские имена, а общие папки, обычные папки, файлы наборов и почтовые ящики остаются на латинице, чтобы их было удобно набирать в консоли.

### Сетевые режимы

| Режим | Когда использовать | Что делает |
|---|---|---|
| `VMnet` | Сервер и компьютеры учащихся находятся в одной виртуальной сети VMware | Службы слушают статический IP и принимают только эту подсеть |
| `LAN` | Класс с физическими компьютерами в одной сети | То же, что VMnet, в сети класса |
| `Tailscale` | Учащиеся подключаются из дома через tailnet | Службы слушают IP Tailscale и принимают только `100.64.0.0/10` |
| `VPN` | У вас своя WireGuard, OpenVPN или другая VPN | Службы слушают IP адаптера VPN и принимают только `VpnClientCidr` |

Домен всегда публикуется на статическом локальном IP. В режимах Tailscale и VPN он также публикуется на IP туннеля. Режим можно сменить в любой момент командой `Set-NetworkMode.ps1`.

## Установка шаг за шагом

### 1. Установите Windows Server 2025

Есть два способа.

**С ISO ответов.** Соберите небольшой диск с автоматической установкой и набором лаборатории. В Linux:

```bash
./unattend/new-answer-iso.sh -p ru-RU -o lab-answers.iso
```

В Windows:

```powershell
.\unattend\New-AnswerIso.ps1 -Region ru-RU -OutFile .\lab-answers.iso
```

Регион может быть `en-US`, `es-MX`, `es-ES` или `ru-RU`. С `ru-RU` используйте русский ISO Windows Server: раскладка по умолчанию английская, русская доступна, часовой пояс московский. Скрипт спросит пароль администратора. С `-g` в Linux или `-GeneratePassword` в Windows он создаст пароль и сохранит его рядом с ISO в файле, который можете прочитать только вы. С `-a` или `-AutoStart` установка лаборатории начнётся сама при первом входе. Используйте `-f bios` или `-Firmware bios`, если ваша виртуальная машина не использует UEFI.

Создайте виртуальную машину с оригинальным ISO Windows Server 2025 в первом приводе CD и ISO ответов во втором. Windows установится без вопросов, назовёт сервер по вашей конфигурации и скопирует набор в `C:\Lab`.

**Вручную.** Установите Windows Server 2025 с рабочим столом, войдите как администратор и скопируйте папку репозитория в `C:\Lab`.

### 2. Выполните шаги по порядку

Откройте PowerShell от имени администратора и перейдите в папку установки:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
cd C:\Lab\setup
```

Запускайте скрипты в таком порядке. Каждый по завершении выводит итог и подсказывает следующий.

| Порядок | Команда | Что делает |
|---|---|---|
| 1 | `.\Set-ServerNetwork.ps1 -Restart` | Задаёт статический IP, создаёт правила брандмауэра, настраивает время и переименовывает сервер. Перезагружает |
| 2 | `.\Install-DomainController.ps1 -Restart` | Устанавливает AD DS и DNS и создаёт лес. Генерирует пароль DSRM. Перезагружает |
| 3 | `.\Set-DomainDns.ps1` | Серверы пересылки, обратная зона и адреса, на которых публикуется домен |
| 4 | `.\New-DirectoryStructure.ps1` | Подразделения, группы, политика паролей, делегирование, вымышленные сотрудники, служебные учётные записи и учёт компьютеров |
| 5 | `.\New-FileShares.ps1` | Личные папки, общие материалы, слепой ящик для флагов и конфиденциальная папка |
| 6 | `.\Set-GroupPolicies.ps1` | Кто может входить на контроллер, и динамические обои |
| 7 | `.\Protect-DomainController.ps1` | Усиление защиты и аудит контроллера |
| 8 | `..\engine\Initialize-Challenges.ps1` | Создаёт соль флагов, размещает задания и готовит наборы |
| 9 | `.\Add-Administrators.ps1 -Path ..\config\administrators.csv` | Добавляет преподавателей |
| 10 | `.\Add-Students.ps1 -Path ..\config\students.csv` | Добавляет учащихся и готовит их личные наборы |
| 11 | `..\services\Register-Services.ps1` | Регистрирует интранет, неожиданный порт, почту, монитор и проверку |
| 12 | `..\web\Install-Web.ps1` | Устанавливает Node.js, собирает сайт, создаёт сертификат и публикует сайт |
| 13 | `.\Test-Lab.ps1` | Проверяет всё и показывает включённые уязвимости |

Если хотите выполнить всё за один раз, `.\Install-Lab.ps1 -Start` пройдёт ту же последовательность, переживёт перезагрузки и продолжит сам. `.\Install-Lab.ps1` без параметров показывает, на каком шаге установка, а `-Resume` продолжает после исправления ошибки. Если вы положили файлы CSV преподавателей и учащихся в `config` до начала, этот запуск добавит и их.

Созданные пароли сохраняются в `C:\Lab\data` и доступны только SYSTEM и администраторам. Перенесите пароль DSRM и пароль администратора с сервера в надёжное место.

### 3. Присоедините компьютеры учащихся

На каждом компьютере от имени локального администратора запустите `client\Join-Lab.ps1`. Без параметров он только проводит диагностику. `-Prepare` настраивает DNS и сеть для выбранного режима, `-Join -User <имя_пользователя>` присоединяет компьютер к домену в подразделение рабочих станций, а `-Leave` выводит его из домена и возвращает всё как было.

## Добавление из CSV

Файлы CSV принимают заголовки на русском, английском или испанском, разделитель запятая или точка с запятой, кодировка UTF-8 или, если файл сохранён в русском Excel, Windows-1251. Пустые столбцы заполняются сами: имя пользователя строится из первой буквы имени и первой фамилии, почта из домена, а пароль генерируется. Кириллица в именах транслитерируется в латиницу, поэтому Иван Петров получит имя пользователя `i.petrov`.

Учащиеся, через `Add-Students.ps1`:

```csv
имя,фамилия,пользователь,почта,пароль,группа
Анна,Пример Один,,,,
Илья,Пример Два,i.primer2,,,
```

Английский вариант заголовков: `firstname,lastname,username,email,password,group`, испанский: `nombre,apellidos,usuario,correo,contrasena,grupo`.

Преподаватели и администраторы, через `Add-Administrators.ps1`:

```csv
имя,фамилия,пользователь,почта,пароль,роль
Преподаватель,Пример,adm.prepodavatel,,,преподаватель
Домен,Пример,adm.domen,,,администратор
```

Роль `instructor` (в русском CSV `преподаватель`) управляет подразделением лаборатории через делегирование и может пользоваться удалённым рабочим столом, не будучи администратором домена. Роль `admin` (`администратор`) также добавляется в Domain Admins. Каждый запуск оставляет CSV с учётными данными в `C:\Lab\data`; удалите его после раздачи.

Каждый учащийся получает постоянный идентификатор (`student1`, `student2` и так далее), личную папку на диске `H:`, собственное подразделение внутри `Sandbox` с полным контролем для практики и свой набор заданий. Личные флаги выводятся из этого идентификатора, поэтому учётную запись можно переименовать, ничего не сломав.

## Динамические обои

Каждый, кто входит на компьютер домена, будь то учащийся, преподаватель или администратор, видит обои с логотипом клуба, своим полным именем, ролью, учётной записью, компьютером и датой. Обои рисуются заново при каждом входе в разрешении экрана. Если что-то пошло не так, остаются базовые обои клуба. Скрипт лежит в `NETLOGON\wallpaper`, а включает его GPO обоев, связанная с доменом.

## Задания

Семь дней, 36 заданий: 620 обязательных баллов и 100 дополнительных. Первый, кто решил задание, получает 5 дополнительных баллов, завершённый день даёт 25, а сдача чужого флага отнимает 10.

| День | Тема | Что отрабатывают учащиеся |
|---|---|---|
| 1 | Знакомство с Windows | Собственная карта базовых понятий |
| 2 | Командная строка | Переменные среды, скрытые файлы, поиск внутри файлов, PATH, запланированные задачи |
| 3 | Windows изнутри | Реестр, альтернативные потоки NTFS, ссылки и SID |
| 4 | Автоматизация на PowerShell | Поиск в больших журналах, построение структур, сборка частей по порядку, экспорт в CSV и JSON |
| 5 | Сеть и вся цепочка | Сетевые настройки, обход DNS, SMB с цепочкой учётных данных, неожиданный порт и внутренняя почта |
| 6 | Active Directory | Разведка пользователей, групп, компьютеров и учётных записей с SPN |
| 7 | Администрирование и защита | GPO с часами входа, аудит процессов, обои с фильтром по группе, создание пользователей и отчёт с разделом о защите |

Каждый день заканчивается отчётом. Задания четвёртого и седьмого дней без флага проверяются автоматически: проверка читает папку учащегося, его подразделение и SYSVOL.

В лаборатории есть контроль честности: свой флаг у каждого учащегося, владелец NTFS у каждой сдачи, пять приманок, которые найдёт только тот, кто выгружает файлы целиком, и поведенческие признаки. Отчёт формирует `engine\Get-IntegrityReport.ps1`, и он никогда не появляется в публичном рейтинге. Сама по себе приманка ничего не доказывает: это повод поговорить с человеком.

## Намеренные уязвимости

Это уязвимости, которые лаборатория оставляет открытыми намеренно. Каждую можно отключить в разделе `Weaknesses` конфигурации.

| Переключатель | Уязвимость | Чему учит |
|---|---|---|
| `ServiceAccountsWithSpn` | Служебные учётные записи с SPN | Перечислять SPN и понимать Kerberoasting. Их пароли длинные и случайные, в этом и состоит защита |
| `DirectoryNotes` | Чувствительные данные в атрибутах Description и info пользователей, компьютеров и групп | Каталог хранит больше, чем показывает обычный список |
| `TokenInDnsSuffix` | Секрет, распространяемый через список суффиксов DNS в GPO | Полная сетевая конфигурация показывает больше, чем простой `ipconfig` |
| `SharedSmbAccount` | Общая учётная запись SMB, пароль которой и есть этот секрет | Повторное использование учётных данных и цепочки подсказок |
| `InternalHttpIntranet` | Интранет по HTTP без шифрования с внутренними именами | Автоматический обход DNS и чтение HTML |
| `UnexpectedBannerPort` | Служба слушает там, где не должна | Сканирование портов и общение с неизвестной службой |
| `PlaintextMail` | Почта SMTP и POP3 без TLS | Протоколы в открытом виде и аутентификация, видимая в сети |
| `DelegatedSandboxOUs` | Учащиеся имеют полный контроль над своим подразделением | Делегирование в AD и его риски |
| `StudentsCreateGpos` | Учащиеся состоят в Group Policy Creator Owners | Создание и связывание GPO и почему эта группа чувствительна |
| `HighLockoutThreshold` | Блокировка учётной записи после 10 попыток | Почему высокий порог облегчает распыление паролей |

Делегирование, которое позволяет учащимся присоединять компьютеры к подразделению рабочих станций, тоже известный риск: любой, кто может присоединять туда машины, может сбросить пароль других машин в этом подразделении.

Что остаётся защищённым: квота на добавление компьютеров равна нулю, учащиеся не входят на контроллер, преподаватели не являются администраторами домена, ящик для флагов слепой, каждое конфиденциальное личное дело читает только его владелец, брандмауэр блокирует все входящие подключения, кроме сети лаборатории, диспетчер печати и NetBIOS отключены, LSA работает в защищённом режиме, WDigest не хранит пароли в открытом виде, расширенный аудит включён. Аудит создания процессов намеренно оставлен выключенным, потому что это упражнение седьмого дня.
